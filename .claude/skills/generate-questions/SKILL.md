Generate a complete grammar question file for the specified rule. Write the result to the given filename using the Write tool.

## Arguments

The user passes: `<rule-id> <rule title> <output-filename> [--lang fr|de] [--count 25|10]`

- `--lang` defaults to `fr`. When `de`, all content must be in German.
- `--count` defaults to `25` (20 MCQ + 5 INPUT). Use `10` for German (8 MCQ + 2 INPUT).

The output file should be written to `questions/<lang>/` (canonical source), e.g. `questions/de/01-01.txt`.

## File Header

Start the file with:
```
RULE <rule-id>: <rule title in target language>
Generated by: sonnet
Total: <N> MCQ + <M> input = <T> questions
```

## MCQ Format (questions 001–0NN)

```
BEGIN QUESTION
ID: <rule-id>-<NNN>
TYPE: MCQ
PROMPT: <instruction in target language>
RIGHT ANSWER: <correct answer>
EXPLANATION: <why correct, in target language>
WRONG ANSWER: <plausible wrong answer>
EXPLANATION: <why wrong, in target language>
WRONG ANSWER: <plausible wrong answer>
EXPLANATION: <why wrong, in target language>
WRONG ANSWER: <plausible wrong answer>
EXPLANATION: <why wrong, in target language>
END QUESTION
```

Default to 4 choices (1 right + 3 wrong). Use 3 when more feel forced; 5 for "which sentence is correct" questions.

MCQ wrong answer diversity per question:
- ~1–2 on-topic (same grammar family, different form — e.g. wrong person, wrong tense ending)
- ~1 adjacent topic (e.g. imparfait instead of passé composé; for German: wrong case, wrong gender)
- ~1 left-field plausible (different construct a learner might confuse)

## INPUT Format

```
BEGIN QUESTION
ID: <rule-id>-<NNN>
TYPE: INPUT
PROMPT: <brief instruction in target language>
PHRASE: <full sentence with ___ marking the blank>
RIGHT ANSWER: <word(s) to fill in>
EXPLANATION: <why correct, in target language>
WRONG ANSWER: <plausible wrong answer 1>
EXPLANATION: <why wrong, in target language>
...
END QUESTION
```

### INPUT question counts by --count

- **--count 25** (default): 5 INPUT questions (021–025), each with **5–10 wrong answers** (aim for 5)
- **--count 10** (German): 2 INPUT questions (009–010), each with **4–8 wrong answers** (aim for 5, minimum 4)

INPUT wrong answers should cover the most likely learner errors: wrong person/number, wrong tense, wrong auxiliary, wrong participle form, wrong agreement, wrong case/gender (German).

**CRITICAL — single blank only**: The PHRASE must contain **exactly one `___`**. Multi-blank questions are not supported. If a rule naturally involves two elements, fill in all but one directly in the PHRASE text.

**PROMPT field**: write only the brief instruction — do NOT include "Instruction:" as a prefix.

## Language-Specific Rules

### French (--lang fr)

- All prompts, answers, and explanations must be in **French**
- Use « ... » quotation marks for phrases
- Vary subjects (je, tu, il, elle, nous, vous, ils, elles)
- Vary verbs — do not repeat the same verb more than 3–4 times across the file
- RIGHT ANSWER should use proper capitalisation
- WRONG ANSWERs must never duplicate the RIGHT ANSWER
- All answers must produce grammatically well-formed French when slotted into the sentence

### German (--lang de)

- All prompts, answers, and explanations must be in **German**
- Use „..." (German quotation marks) for phrases
- Vary subjects (ich, du, er, sie, es, wir, ihr, sie/Sie)
- German prompts: "Ergänzen Sie:", "Konjugieren Sie:", "Welche Form ist richtig?"
- German grammar terms: "Akkusativ", "Dativ", "Nominativ", "Konjugation", "Wortstellung", "Artikel", "Genus", "Plural"
- Case-specific distractors (nominativ vs. akkusativ vs. dativ)
- Gender-specific distractors (der/die/das confusion)
- RIGHT ANSWER should use proper capitalisation (nouns always capitalized in German)
- WRONG ANSWERs must never duplicate the RIGHT ANSWER
- All answers must produce grammatically well-formed German when slotted into the sentence

## General Content Rules (all languages)

- Wrong answers must be plausible learner mistakes — not random noise
- WRONG ANSWERs must be distinct from each other (no near-duplicates)
- Vary contexts — do not repeat the same verb/sentence structure more than 3–4 times

## Output

Generate all questions covering the grammar rule thoroughly, then write the complete file to the specified output path.
